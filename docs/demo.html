Agentic Business Central Operations

A customer request becomes an inventory-aware proposal. A human approves it before the simulated ERP creates the sales order.

Run the interactive app: execute bash scripts/run-local.sh from the repository root and open localhost:5058. This page is an offline showcase of real screenshots. The application uses seeded, in-memory data and deterministic extraction; no Azure, real ERP or live AI connection is required.
